# Planos Peru

## Descripción

Planos Peru Intranet es un proyecto web dedicado a la creación y gestión de planos arquitectónicos. Ofrecemos herramientas y recursos para arquitectos y diseñadores que buscan optimizar su flujo de trabajo.

## Características

- Seguimiento de actividades, tarea y proyectos
- Gestión de expedientes
- Ubicación de Proyectos
- Calendario
- Tablero Kanban
- Dashboard
- Gestión de Usuarios

## Notificaciones

Todos
- Cuando cambie estado de expediente de las OTS
- Cuando sean las 1:00, 1:50 y 6:30
Admin
- Cuando se envie un reporte de gastos.
Usuario
- Cuando rechacen un reporte de gastos.

## Tablas

Todas las tablas principales deberian tener al menos estas caracteristicas usando datatables
- Listar, crear, editar, borrar
- Buscar
- Filtrar
- Ordenar
- Exportar a Excel
- Responsive
